# react-ai-builds

Portfolio repo for the Instagram channel **[@devshipped](https://www.instagram.com/devshipped/)** — each project is a small SaaS tool / SPA built with AI-assisted prompt engineering, shipped for real (not a demo).

## Adding a new project

Each project lives in its own folder under `applications/<project-name>/`:

```
applications/<project-name>/
├── README.md   # what it is, link to prompt.md, Instagram handle/link
├── prompt.md   # the exact prompt used to build it
└── app/        # the actual app (Next.js project)
```

When adding a project:

1. Scaffold the app inside `applications/<project-name>/app/`.
2. Write `prompt.md` with the exact prompt that was used to build it.
3. Write `README.md` with a short description, a link to `prompt.md`, and the Instagram handle/link.
4. Add a row for it in the root [README.md](./README.md) projects table.
5. Do **not** commit `node_modules/`, `.next/`, or other build output — the root [.gitignore](./.gitignore) covers common cases, but double-check before committing a new project.
6. Never commit secrets or `.env*` files. This repo is public.

## Stack

Next.js · TypeScript · Tailwind CSS · Framer Motion

## Note on nested AGENTS.md files

Files named `AGENTS.md` inside `applications/*/app/` (auto-generated by `next dev`) belong to that specific Next.js app, not this repo — leave them as-is.
