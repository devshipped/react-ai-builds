# Pomodoro Timer 🍅

A Pomodoro timer with a hand-drawn SVG tomato as the progress indicator — fills bottom-up as focus/break sessions run, with a live countdown in the tab title and browser notifications when a session ends.

Built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

Part of [react-ai-builds](../../) — I post the full build process on Instagram: **[@devshipped](https://www.instagram.com/devshipped/)**

The exact prompt used to build this is in [prompt.md](./prompt.md).

## Getting Started

```bash
cd app
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
